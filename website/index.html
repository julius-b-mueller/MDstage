Was Main Desk kann

Alles für die Regie,
nichts Überflüssiges

Speziell entwickelt für den professionellen Bühneneinsatz. Kein Overhead, keine Ablenkung.

🎬

Live-Ansicht

Separates Fenster für Bühnen- oder Regiemonitor zeigt aktuellen und nächsten Cue, Go/Back-Tasten, Audio-Fortschritt und Varianten-Auswahl.

🎵

Nahtlose Audio-Übergänge

S/L/F-System (Start / Loop / Finish) für samplegenaue Übergänge ohne Klick oder Stille — via WebAudio AudioBufferSourceNode.

🎛

MIDI & OSC

X32-Mikrofon-Routing, Trigger-Noten, MIDI Timecode (MTC 25fps) und custom OSC-Nachrichten pro Cue. Go/Back via MIDI-Controller.

📝

Markdown-Workflow

Skript und alle Cues leben in einer einzigen .md-Datei. Git-versionierbar, im Texteditor bearbeitbar, auf mehreren Rechnern nutzbar.

📤

Export

PDF und DOCX-Export mit Deckblatt, Inhaltsverzeichnis, Rollennamen in Farbe und allen Cue-Informationen — druckfertig für Probe und Aufführung.

🖥

Dual-Audio-Ausgang

Getrennte Kanäle für Haupt- und Monitor-Mix auf einem Aggregate Device. Pro Cue eigene Monitor-Datei (z.B. mit Klickspur).

Hinweis: Unsignierte Software

macOS zeigt beim ersten Start eine Warnung von Gatekeeper. So öffnest du Main Desk trotzdem:

Option 1 – Systemeinstellungen:

Systemeinstellungen → Datenschutz & Sicherheit → ganz nach unten scrollen → „Main Desk" → „Trotzdem öffnen"

Option 2 – Terminal (einmalig):

xattr -cr /Applications/Main\ Desk.app

Danach startet die App normal. Der Befehl muss nur einmal ausgeführt werden.

Windows SmartScreen zeigt eine Warnung beim ersten Start. So gehst du vor:

  1. Klicke auf „Weitere Informationen"
  2. Klicke auf „Trotzdem ausführen"

Diese Warnung erscheint nur beim ersten Start, nicht danach.

Für AppImage: Datei ausführbar machen, dann starten: 

chmod +x MainDesk-linux-x64.AppImage
./MainDesk-linux-x64.AppImage

Für .deb (Debian/Ubuntu):

sudo dpkg -i MainDesk-linux-x64.deb
